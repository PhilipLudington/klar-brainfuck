# klar-brainfuck

A Brainfuck interpreter written in Klar.

## Project Structure

```
src/main.kl      # Interpreter implementation
examples/*.bf    # Example Brainfuck programs
```

## Build & Run

```bash
klar build src/main.kl   # Build the interpreter
cp examples/hello.bf program.bf
./main                   # Run (reads program.bf)
```
